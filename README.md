# XRemini V1

XRemini is a Flutter starter app for an AI photo enhancer.

## Included
- Premium dark UI
- Splash screen
- Home screen
- Daily/demo credit counter
- Gallery photo picker
- Enhancement selection
- Processing flow
- Before/after result UI
- Rewarded-ad placeholder

## Run
1. Install Flutter.
2. Run `flutter pub get`.
3. Run `flutter run`.
